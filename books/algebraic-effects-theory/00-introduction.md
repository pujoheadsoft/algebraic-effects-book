# 本書の目的

本書の目的は、代数的エフェクトとハンドラーについて、提唱者たちの主要論文をもとに数学的な理解を得ることです。

特に、代数的エフェクトとは数学的に何なのか、そしてハンドラーはどのような数学的構造によって説明されるのかを明らかにすることを目指します。

そのために、必要となる数学的な概念を定義し、定理や具体例を通して、原論文で示された特徴づけに到達していきます。

定理の証明についても必要に応じて示しますが、本筋の理解に必須ではないものは、読み飛ばせるようにします。

# 原論文による特徴づけ

代数的エフェクトとは何なのでしょうか。

提唱者たちによる主要論文にあたってみましょう。

主要論文はいくつかありますが、そのうちの Plotkin と Pretnar による2013年の論文 [Handling Algebraic Effects](https://homepages.inf.ed.ac.uk/gdp/publications/handling-algebraic-effects.pdf) では、代数的エフェクトとハンドラーの両方が数学的に特徴づけられています。

## 代数的エフェクト

この論文の Abstract の冒頭では、代数的エフェクトについて次のように述べられています。

> Algebraic effects are computational effects that can be represented by an equational theory whose operations produce the effects at hand. The free model of this theory induces the expected computational monad for the corresponding effect.

日本語にすると、代数的エフェクトとは、対象としているエフェクトを生み出す演算をもつ等式理論によって表現できる計算エフェクトである、ということです。

さらに、この理論の自由モデルは、対応するエフェクトに期待される計算モナドを誘導すると述べられています。

これを理解するには、少なくとも次の疑問に答える必要がありそうです。

1. 計算エフェクトとは何か。
2. 演算がエフェクトを生み出すとはどういうことか。
3. 等式理論によって表現できるとはどういうことか。
4. 自由モデルとは何か。また、それが計算モナドを誘導するとはどういうことか。

## ハンドラー

同じ論文の導入部では、ハンドラーの数学的な考え方について次のように述べられています。

> The main idea is that 
> (1) handlers correspond to (not necessarily free) models of the equational theory; and 
> (2) the semantics of handling is given using unique homomorphisms that target such models
> and are induced by the universal property of the free model.

日本語にすると、主な考え方は次の二点です。

1. ハンドラーは、等式理論の、必ずしも自由ではないモデルに対応する。
2. ハンドリングの意味論は、そのようなモデルを終域とし、自由モデルの普遍性によって誘導される一意な準同型を用いて与えられる。

ハンドラーとは、エフェクトを伴う計算で行われる演算を、どのように処理するかを指定する仕組みです。

この仕組みについても、次の疑問が生じます。

1. ハンドラーが理論のモデルに対応するとはどういうことか。
2. なぜハンドリングを準同型によって表せるのか。
3. 自由モデルの普遍性は、ハンドリングの意味をどのように決定するのか。
4. この考え方を、さまざまな代数的エフェクトに対してどのように適用できるのか。

このように、代数的エフェクトとハンドラーの数学的な説明には、自由モデルという共通の概念が登場します。

本書では、これらの疑問に答えることを中心的な到達点とします。

# 本書の進め方

これらの特徴づけを理解するには、いくつかの数学的な概念が必要です。

本書では、最終的に理解したい主張から逆算し、必要な概念を順番に導入していきます。

まず、代数的エフェクトを演算と等式によって表現するためには、演算や法則を数学的にどのように扱うのかを理解する必要があります。

そこで、代数理論とそのモデルから始めます。

次に、演算記号と等式によって代数理論を記述する方法を説明します。これにより、具体的な演算と法則から理論を与える方法が明らかになります。

続いて自由モデルを導入し、その普遍性を説明します。

自由モデルが重要なのは、二つの理由からです。

一つは、自由モデルを構成する関手と忘却関手の間の随伴から、モナドが誘導されることです。これが代数的エフェクトと計算モナドを結び付けます。

もう一つは、自由モデルの普遍性が、ハンドリングの意味を与える準同型の存在と一意性を保証することです。

このようにして得られた数学的な結果を計算エフェクトへ適用し、代数的エフェクトの特徴づけからハンドラーの意味論へと進みます。

# 本書の構成

第I部では、代数理論とそのモデル、等式による提示、自由モデルとその普遍性、自由・忘却随伴から誘導されるモナドを扱います。

第II部では、それらの結果を計算エフェクトへ適用し、代数的エフェクトとハンドラーの数学的な特徴づけを説明します。ここが本書の中心部分です。

第III部では、発展的な話題として、モナド上の代数的演算を扱います。既に与えられたモナドの演算が代数的であるための条件を調べ、generic effect との対応を明らかにします。さらに、その結果の一般化についても説明します。

なお、最初は有限個の引数をもつ演算を扱いますが、代数的エフェクトでは無限個の引数をもつ演算も現れます。そのため、必要な段階で有限アリティを超える場合も扱います。

# 前提知識

本書は、圏論の基本的な概念とモナドについて理解している読者を想定しています。

具体的には、圏、関手、自然変換、有限積、随伴などを既知とします。必要に応じて、これらの性質を参照します。

一方、普遍代数学については前提とせず、本書に必要な概念を第1章で説明します。

また、本書は主に数学的な理論を扱います。個別のプログラミング言語におけるエフェクト機構の実装方法や、エフェクトライブラリの使い方を網羅することは目的としません。
